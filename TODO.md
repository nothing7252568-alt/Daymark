# Daymark outcome checklist

- [x] **Onboarding, navigation, and daily check-ins.** Build a habit app with daily check-ins and streaks. Provide onboarding, intuitive navigation, and a one-thumb Today flow with date, status, an at-a-glance completion summary, and one-tap check-in. Keep successful check-ins visible and recoverable; let users undo the latest check-in for a completed weekly goal.
- [x] **Habit creation and lifecycle management.** Provide create/edit flows for habit name, schedule or frequency, start date, reminder preference/time, and optional notes. Support pausing, resuming, archiving, restoring, and confirmed permanent deletion. Confirm before discarding unsaved form edits so a backdrop/system-back action cannot silently lose work.
- [x] **Streaks and progress.** Show current and best streaks, completion history, and success feedback after check-ins. Count three-per-week habits as three distinct check-ins toward one weekly goal; keep an incomplete goal available, retain the prior weekly streak through Sunday, and stop counting after the weekly target is met.
- [x] **Habit search and filters.** Provide search by habit name and filters for completion period, schedule, and active, paused, archived, or all status. Show a clear empty-result state and a path to clear filters.
- [x] **Notifications and settings.** Provide native local habit reminders that follow saved frequency/time, begin no earlier than the habit start date, stop for paused/archived habits or a met weekly goal, and reconcile after app resume. Ask permission only when the user enables reminders; explain denied or unsupported/web states and where to recover permission. Provide notification preferences, haptics, reduced-motion, week-start, export, and history-reset controls.
- [x] **Persistence, resilient states, and accessibility.** Persist onboarding, habits, check-in dates, and settings locally across app restarts; let core use work offline without an account or network. Cover loading, empty, offline, permission, error, success, retry, and recovery states with responsive, polished mobile UI. Provide readable contrast, large touch targets, accessible labels/roles and semantic headings, visible keyboard focus, and reduced-motion-aware feedback. Help users complete the main task quickly on a phone.

**Validation note:** TypeScript, lint, unit tests, and Expo Web export pass. Actual local-notification permission and delivery remain native-device behaviors and are not verified by Expo Web Preview.
